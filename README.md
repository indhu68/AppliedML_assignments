# Applied Machine Learning Assignments

This repository contains my hands-on assignments and laboratory work completed as part of an Applied Machine Learning course. It includes Jupyter Notebooks demonstrating the implementation and exploration of machine learning concepts, algorithms, and techniques.

## Overview

The repository covers different areas of applied machine learning, progressing from foundational machine learning concepts to deep learning and transformer-based approaches.

The notebooks provide practical experience with model development, training, evaluation, and experimentation using Python.

## Topics Covered

- **Machine Learning Fundamentals:** Introduction to machine learning concepts and practical implementations.
- **Linear Classification:** Exploring linear classification techniques and their applications.
- **Model Evaluation and Improvement:** Evaluating model performance and exploring approaches to improve predictive results.
- **Decision Trees:** Understanding and implementing tree-based learning algorithms.
- **Unsupervised Learning:** Exploring unsupervised learning techniques and discovering patterns in data.
- **Neural Networks:** Implementing neural network models and understanding their learning process.
- **Deep Learning:** Working with deep learning concepts and model implementations.
- **Sequence Modeling:** Exploring machine learning approaches for sequential data.
- **Text Processing:** Applying machine learning techniques to text-based data.
- **Transformers:** Exploring transformer architectures and their applications.
